# Spec: Восстановление стабильности медиа и производительности

## Цель
Исправить отображение видео и вернуть быструю загрузку иконок/эмодзи в Discord Lab, которые сломались после введения тотального проксирования.

## Требования
1. **Выборочное проксирование**: Использовать прокси только для вложений Discord (`attachments`), которые имеют срок жизни. Эмодзи и иконки должны грузиться напрямую через CDN Discord для скорости.
2. **Полная асинхронность**: Заменить синхронный `requests.head` на асинхронный `httpx` на бэкенде.
3. **Корректные заголовки**: Убедиться, что `Content-Length` и `Accept-Ranges` передаются правильно для поддержки перемотки видео.

## Риски и граничные случаи
- **CORS**: Прямые ссылки на эмодзи могут блокироваться браузером (хотя обычно нет). Если заблокируют — вернем прокси только для них.
- **Таймауты**: Ожидание HEAD запроса может замедлять первый запуск видео.
